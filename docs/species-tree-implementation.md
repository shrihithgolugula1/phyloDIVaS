# Interactive species tree implementation

The former preview did not use sequence data. It resolved NCBI TaxIDs, counted edges in each NCBI parent lineage, used those counts as pairwise distances, and reconstructed an unrooted Neighbor-Joining tree. No genes were retrieved, no alignment was performed, and the Newick orientation was treated as if it were a biological root. This could display Homo and Gorilla as sisters because an unrooted distance split does not encode the rooted Homo-Pan-Gorilla ordering.

The current preview resolves each selected name or TaxID through NCBI Taxonomy and constructs the selected taxa's minimum rooted taxonomy subtree. It then queries TimeTree for published divergence estimates and uses those estimates to calibrate the displayed nodes and branch lengths in millions of years. Unary nodes and reference-only labels are removed while the MRCA root is preserved. Accepted names, NCBI TaxIDs, parent paths, TimeTree estimates, and previously generated TaxID sets are cached in memory. Subspecies remain distinct leaves when the references resolve them distinctly; synonyms resolving to the same NCBI TaxID are represented once under NCBI's accepted scientific name.

If TimeTree does not provide an estimate for a node, the service retains the NCBI taxonomy topology and clearly leaves that node uncalibrated rather than inventing a date. The interactive preview is a reference species tree, not a gene tree. The analysis pipeline's later OrthoFinder tree remains the sequence-based result.

The optional tree-of-life comparison builds a second NCBI/TimeTree reference tree containing every selected taxon plus representative bacterial, archaeal, fungal, protist, plant, invertebrate, fish, amphibian, bird, and mammal lineages. phyloDIVaS sends both Newick strings to Big Tree Viewer in a client-side session payload, where shared tips are connected and reordered to reduce crossings. The interface explicitly describes this as representative context rather than the complete TimeTree database because TimeTree does not expose its complete tree through the public API and its terms prohibit redistribution without permission.

The interface displays a conservative dS-saturation warning when the selected species span more than 50 million years. This is a screening threshold, not a universal biological boundary: synonymous-site saturation depends on the genes, lineages, and substitution model used in an analysis.
